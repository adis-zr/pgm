## 1. What it does (v0.1, 24 Nov 2026)

`coarse_envelope.py`: canonicalize (equality diagonal for repeated occurrences; unaries, evidence indicators and card-1 variables absorbed; factorless variables collapse to a scalar + EXACT rows) -> exact projective quotient (states share a class iff every incident complete slice is positively proportional; zero slices a separate signature; scales = first positive entry ratios; checked entrywise: L = U) -> if the quotient reduced a domain or left only unaries and its forecast is admitted, ONE executor solve gives every original coordinate through the decoder (EXACT points compacted outward 2^-52) -> otherwise approximate grouping on the quotient: per-state concatenated centered log-slice profiles (positive tables only; zeros -> typed skip), L-infinity farthest-pair seeds, canonical ties; gauge = unit vs log-slice centering by the exact local R (ties unit) -> FAST baseline witness: lower solve; if R finite, the one-lower-solve bound `[mu/(mu+R(1-mu)), R mu/(R mu+1-mu)]` on every original coordinate (decoder composed through the stages); if the contract is not met and the upper solve is admitted, the two-envelope ratio with positive complement sums; intersections retained -> FIT: one local Chebyshev LP per positive factor in a supervised child (`lp_worker.py`, scipy highs, sparse two inequalities per entry, one pinned theta per incidence/class, one center per cell; storage admitted before the matrix), rationalized (den <= 2^16), per-factor retention by the smaller EXACT local range, one witness -> refinement witnesses (max (U-L)/(U+L) cell, largest nonsingleton class, farthest split / canonical balanced) up to 3 witnesses in total (FAST: 2 refinements; FIT: fitted gauge + 1 refinement). Publication = the executor's point-selection rule (lower endpoints then greedy fill), acceptance 0<=lo<=pt<=hi<=1 and width <= 2 eps per row; a variable publishes only when all its rows pass. Nothing is published without Z_L > 0; an all-zero factor or a zero exact quotient certifies ZERO_EVIDENCE. Refusals are typed (DEADLINE / MEMORY / BITS / FORECAST / executor kinds); a deadline inside a witness publishes the retained intersection when time remains before the hard budget, else DEADLINE.

Resource contract: `--budget` is the hard worker deadline from process start (publication allowed until it), `--admission-stop` (3.5 s) stops admitting new work; BIT_CAP 4,096 on constructed rationals (operand bounds checked before products); CONSTRUCTOR_BYTES 128 MiB named-container estimate (not an RSS bound); the executor's USABLE 2.5 GiB policy and kernel cap; FIT allowance 1.0 s incl. worker setup. `feature_bounds()` gives bounded local features (normalized g, decoded coarse feature, two-sided ratio, one-solve bound) on tiny exact coarse joints for controls only.

`hp_gen.py`: the frozen twelve-input generator (tag HINTON-PEARL-COMPILER-2026-11-23). `check_hp.py`: 64 independent controls vs an exact enumerator. `run_hp.py`: the three-arm supervised runner (BASE / COARSE_FAST / COARSE_FIT, 4 s / 3 GiB, cycling arm order, --confirm reverses).
