## 2. Proof-to-code mapping of the lifted proposal (brief section 3)

Notation: parent canonical model `M_par` (identity: the base canonical model `M`; or the exact quotient parent `stage_model(M, Cz1)`), fine state `z`, approximate stage `(classes, Cz) = check_candidate(M_par, classes, scales)`.

**Target.** `W'(z) = prod_v psi_v(z_v) prod_f f(z_f)` on `M_par` (the scalar `M_par.scalar` is owned once and cancels in every ratio; `lifted_decoder.parent_weight` includes it for the oracle). In the stream the fine tables are `integerize(canon_to_model(M_par))` -> `fns_F`, `scale_F`: `W_int(z) = scale_F W'(z)` exactly (`pac_actions.LiftedStream._l_fine_tables`); their float tables `IG.ft_from_int` carry envelopes `rho` (Lemma F of the accepted note) and exponents `e` with `E_fine = sum e`.

**Upper envelope (support, pointwise).** `coarse_envelope.check_candidate` recomputes from the source entries `u_v(a) = psi_v(a) prod lambda`, `A_v(c) = sum_{a in c} u_v(a)`, the product decoder `d_v(a|c) = u_v(a) / A_v(c)` (uniform on a zero-mass class), and per-cell exact maxima `U_f(C)` of the gauge residual. The checked pointwise relation `0 <= W'(z) <= G_U(c(z)) d(z|c(z))` with `G_U(c) = prod_v A_v(c_v) prod_f U_f(c_f)` is the module's upper-envelope sandwich (`coarse_envelope.py:171-219`; independent enumeration in `check_hp.lift_sum` and now `lifted_decoder.enumerate_check`, raising `Defect` on any violated state). Zero decoder entries receive zero proposal counts, positive ones at least one count: `r_v(a|c) > 0 <=> d_v(a|c) > 0` (`lifted_decoder._row_counts`, asserted), so the conditional support is preserved.

**Cap.** The accepted max mini-bucket construction `IG.MBFloat` on the upper coarse model `CE.coarse_model(M_par, Cz, 1)` integerized (`scale_C`): the analysed law `q_C(c)` (replayed exactly by `MBFloat.logq_given`) satisfies `G_U_int(c) <= 2^logU q_C(c) (1 + rho_cap)` where `logU = logU_f + E_U` and `rho_cap` is the accepted widening's cap part (tables vs integers, proposal rows vs exact products, scalar messages) -- reused verbatim in `lifted_widening` parts (b) and (d). Then `W'(z) / (q_C(c) r(z|c)) <= (G_U(c) / q_C(c)) (d(z|c) / r(z|c)) <= B kappa` with `kappa = prod_v max_{c, a: d > 0} d_v(a|c) / r_v(a|c)` (exact rational, `checked_mul`; `LiftedRows.kappa`). In code the certified total cap is `logU_capf = up(up(up(mbp.logU_f + up(log2(1 + rho_cap))) + up(log2(const_f))) + 2^-40)` with `const_f = float_up(scale_F / scale_C x kappa)` and the exact exponent `E_tot = E_fine - E_U` (`LiftedStream._l_sampler`). The implemented weight is `X = 2^(logz - logq - logr - logU_capf + E_tot)` clipped to 1, with the runtime assertion `log2 X <= cap_tol = up(log2(1 + 2 rho_X)) + 2^-40` (certificate defect otherwise; control D9 (iii) makes it fire with an understated cap). Control D5 / D6 / D9 enumerate EVERY parent state and check `X_an <= 1` on the analysed law and that the total proposal mass is 1.

**Response identity.** Identity parent: `g_j(z) = 1[z_v = a]` (`Dm[v]` = identity matrix). Exact parent: `g_j(z) = d_par(a | z_v)` from `CE.compose_decoder(par_stages, v, a)` (exact rational; the float matrix `Dm` deviates by at most `u d`, covered by `resp_rel = 2u` in `rho_f`). The requested original probability is `mu_j = sum_z W'(z) g_j(z) / sum_z W'(z)` (exact decoding of an exact quotient: `coarse_envelope.rows_from_witness` semantics), hence `E_q[X (g_j - mu_j)] = (1 / (B kappa Z')) sum_z W'(z) (g_j(z) - mu_j) = 0` -- control D5 and D6 verify the sum is exactly zero by enumeration (D6 on a true exact-then-approximate composition with nontrivial decoder values). The accepted `IG.Certificate` (PrPl-EB, predictable per-batch parameters, `eps_num` center shift and variance allowance) is used unchanged with `alpha = delta_s / K_s`.

**Zero mass.** `mbp.logU == -inf` on the upper model proves `G_U == 0` everywhere hence `W' == 0`: terminal `ZERO_MASS_PROVED_BY_UPPER_MODEL`. All-zero observed weights never prove anything (the witness stays False; control D7 shows a zero LOWER mass with a positive upper and original mass yields a genuine positive witness only from an observed `X > 0`).

**Numerical widening (`pac_actions.lifted_widening`, operation by operation).** Absolute log2 errors as exact Fractions, `logerr(mag) = u (mag + 1)`: (b) the coarse proposal rows, verbatim from `IG.numerical_widening` (`d_cap`, `d_impl`, `mag_logq`); (c') the fine weight `logz = sum_i fLM_i[idx]`: `nf` log lookups of magnitude `<= R_i` plus `nf` partial sums of magnitude `<= SRf + nf`; (d) the scalar roots, verbatim; (r) the dyadic draw `logr = sum_v (log2 count - 52)`: `n_fine` logs of integers in `[1, 2^52]` (`logerr(52)` each) and `n_fine` partial sums of magnitude `<= n_fine 52`; (k) `log2 const_f`; (e') the final five-term combination on magnitudes `<= mags` plus `5 u |E_tot|` added by the caller. `d_total` is the sum; `rho_X = (1 + 1.45 d_total (1 + d_total)) (1 + rho_fine) - 1` where `rho_fine = comb(rho_i)` is the fine tables' envelope (the implemented X is computed from float tables, the analysed X from exact integers); `rho_cap = (1 + rho_tab)(1 + 1.45 d_cap (1 + d_cap))(1 + rhoU)(1 + rho_X_log) - 1`; `eps_num = 2 rho_X + rho_f + law + trunc` with `law = 4 n_coarse (maxcard_coarse + 2) / 2^53` (realised vs analysed coarse draw law, the accepted bound) and `trunc = n_coarse / 2^900`. The dyadic decoder draw is EXACT (integer uniform vs integer cumulative counts), so it adds no law term. The accepted sampler's positive-probability truncation (`PROB_TRUNC_LOG2 = -900`) omits coarse states of relative row probability `< 2^-900`; their fine target mass divided by `B kappa` is at most the omitted coarse probability (the inherited `trunc` allowance transfers through the envelope because `W'(z) <= B kappa q_C(c) r(z|c)` pointwise), so the same allowance is used; the `delta_log_total <= 1/4` gate stays (typed `NUMERIC_RANGE` refusal). Control D9 checks the implemented log2 X against the exact analysed log2 X on every state (worst deviation 1e-14 vs the bound 9e-12), recomputes two parts directly, fires the cap assertion with an understated cap, and refuses an underflow-prone table typed before any sample.

**Stream risk composition (section 5).** `UPlanner.new_stream`: stream `s` (creation order) receives `delta_s = delta / 2^s` BEFORE its first draw (`risk_ledger`), `alpha = delta_s / K_s` over its frozen response inventory inside the accepted Certificate (union bound over coordinates, as in the accepted engine), the proposal / cap / law / inventory are fixed when the stream becomes READY (`proposal_fingerprint`, re-hashed at the end: `proposal_immutable`), identical semantic streams alias (`stream_key`: kind + target model + inventory (+ class map and decoder)), at most three streams, no refund (`E_used` is the actual elapsed optional time). `sum_s delta / 2^s < delta`: request-wide coverage `>= 1 - delta` by the union bound over streams and coordinates, with each stream's conditional coverage given its creation history (fresh draws from an independent `SeedSequence([seed, s])` generator). The accepted `ZCertificate` stays diagnostic (`Z_over_Ucap_EB_DIAGNOSTIC`). Deterministic rows consume no risk. Cross-stream and deterministic / PAC intersections are on the same original coordinate (`UPlanner.snapshot`); an empty intersection is a recorded `conflicts` entry and the variable is withheld (control D10).

**Lift-only discovery.** The deterministic FAST discovery refuses `BITS` when the diagnostic ratio product `R = prod_f max_C U/L` (the constant of the one-solve bound, which the lifted proposal never uses) exceeds the 4,096-bit cap -- the case on every strongly coupled clique. `UPlanner.discover_fast_lift_only` runs the SAME proposer and the SAME independent checker with the cap raised for that product alone, then re-checks every quantity the lifted proposal consumes (`u`, `A`, `d`, `U`, `L`) under the normal cap (refusing `BITS` otherwise, charge released) and discards `R` (`None`). The candidate is kept out of the deterministic candidate list (never solved natively), its charge enters the ledger identity, and it is offered only as the parent of a lifted stream (control D15).
