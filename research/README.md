# Research organization (consolidation step 1)

Every tracked file is classified in `CLASSIFICATION.json` (generated by
`documentation/consolidation/step1/tools/classify_tree.py`; counts below).  Nothing was deleted or moved out of the
historical campaign paths: the records repository (`pgm-records`, private) references campaign runners, checkers,
oracles and packagers by their `code/cex/hp/...` paths, and the frozen snapshots are pinned references for differential
tests and receipt identity.  What changed is ownership: the live implementations now have ONE canonical owner under
`src/pgm/algorithms/*`, and the historical module paths are alias shims that return the canonical module object.

| class | meaning | where |
|---|---|---|
| production | the installed package (`pgm`): API, contracts, policies, model boundary, planning, runtime, validation, backends, the four algorithm closures | `src/pgm/**` |
| production-shim | alias at a historical path -> canonical module (research / campaign code keeps working; running one as a script re-executes the canonical module) | `code/cex/{newarm,blockres,hp}/*.py` (47), `code/gbidi/supervise.py` |
| specialist | explicit-API implementations on their own representations (CQR, CBI, SF, H4 + native kernel sources) | `code/cex/cqr`, `code/cbi`, `code/sf`, `code/h4a`, `code/native`; entrypoints `pgm.specialists.*` |
| correctness-qualification | portable tests, the pinned parity reference, control suites, conformance tests, step-1 receipts | `tests/`, `code/tests/`, `code/cex/*/check_*.py`, `code/cex/newarm/*qualification*.py`, `documentation/consolidation/step1/qualification/` |
| benchmark-tooling / benchmark-inputs | the external benchmark harness, protocol, provenance, references and the 61 frozen inputs | `benchmarks/external/**`, `code/bench/**`, `code/ext/**` |
| research-campaign-tooling | DGP / HP / BlockRes / CQR / CBI / SF / H4 runners, analyzers, packagers, generators (never imported by production; not wheel contents) | `code/cex/hp/run_*.py`, `code/cex/hp/dgp*.py`, `code/cex/blockres/run_*.py`, ... |
| historical-evidence | frozen snapshots and qualification records (pinned; production never imports them) | `code/cex/{pac,baseline,b0_frozen_v14,newarm_dev}`, `code/cex/newarm/*.json`, `code/build/*`, `code/PINNED_BINARIES.json` |
| documentation / packaging | notes, reviews, architecture, this record; pyproject, ignore rules, tools | `documentation/**`, `*.md`, `pyproject.toml` |

Patch-sensitive campaign checkers (`check_dgp10.py`, `check_dgp.py`, `dgp10_oracle.py`, `dgp9_manifests.py`, the
`tests/`) monkeypatch module attributes by name; the shims hand them the canonical module objects, so their patches
reach the single implementation.  The specialists are reached only through `pgm.specialists._bridge` (the one residual
path manipulation; production inference never imports it).  Items still open are listed under `unfinished` in
`pgm.registry.CAPABILITIES` and in `documentation/consolidation/step1/MIGRATION_MANIFEST.json`.
