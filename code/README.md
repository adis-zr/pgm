# Retained implementations

The supported entrypoint is now `pgm.infer` / `python -m pgm`; see the root README.

This directory preserves the algorithm implementations and historical campaign interfaces used by the research program. Public adapters isolate their module policies, numerical state and resource lifetimes. Existing direct worker commands remain compatibility/reproduction interfaces, not separate recommended user APIs.

The early direct-query, normalization-free, Aggregate DP and general bidirectional documents formerly in this README describe historical commits and remain available in git history. Their old workstation paths and operational status are not installation instructions for the current library.

No method is deleted on the basis of failed dispatch or a missing current adapter. The capability inventory distinguishes automatic UAI methods, specialist representations, broader finite-query interfaces and historical reference snapshots. See `documentation/architecture/CAPABILITIES.md` and `CONSOLIDATION.md`.
