# Unified representation planner: proof-to-code note (v0.1, 24 Nov 2026)

Experimental entry point `cex/hp/unified_planner.py` over the checked primitives of `coarse_envelope.py` v0.2 (byte-identical) and the unchanged certified executor. The accepted v2.13.2 dispatch is not touched. Scheduling estimates (section 4) NEVER enter the correctness argument (sections 1-3): every published number is rebuilt exactly from the original model, the checked representation witness and the executor's enclosures.

## 1. Representation preservation

A candidate is one of three representations of the SAME canonical source `M` (unaries psi, factors, scalar once; evidence restricted out; repeated occurrences on the equality diagonal; card-1 / factorless variables collapsed to EXACT rows + scalar; `canonicalize`, polled and charged).

- **Identity** (`identity_model`): the executor receives `M`'s unaries and factors verbatim with the scalar carried once by the adapter (`run_executor(..., M.scalar, ...)`). Decoder = identity, representation error 0. No profile, no min/max scan, no dense decoder. Claim: `N_v(a) / Z` from the executor's enclosure IS the original coordinate (`rows_identity` reads `SL.p` directly). Proof: the executor's enclosure theorem (reciprocal-envelope labels, exact N/Z in Python, Bernoulli widening) applied to the canonical model, whose joint equals the original restricted joint by construction of `canonicalize` (checked by the enumerator controls A, L).
- **Exact quotient** (`discover_exact` = `exact_profile_classes` + `exact_scales` + `check_candidate`): classes are formed from complete proportional slices over all incident factors; `check_candidate` recomputes `u, A, L, U, d` from the SOURCE entries and verifies `L == U` on every cell (`Cz.exact`), otherwise `Defect`. The sandwich theorem with `L = U` gives `w_L = w = w_U` pointwise, hence `N_v(a) = d_v(a|c) N^coarse_v(c)` exactly (decoder composition theorem of the HP note). A quotient whose coarse cardinalities equal the source cardinalities carries no semantic change: it is recorded as `alias_of = 'identity'` and never solved (no second compulsory solve).
- **Approximate quotient** (`discover_fast` on the exact parent when one exists, else on identity; `refine_cand` nested on the same parent): `check_candidate` recomputes exact cell extrema `L <= h <= U` from the source; the sandwich theorem gives `w_L <= w <= w_U` pointwise under the product decoder. Composition `identity -> exact -> approximate` is sound because the exact stage has zero error (its lifted model IS the source model); `compose_decoder` multiplies the stage decoders (`checked_mul`). No approximation is ever built on an approximation (the parent of every approx candidate is `identity` or the exact candidate: `discover_fast(parent)`, `refine_cand` keeps `cand.parent`).

## 2. Original-query interval recovery and intersection

`rows_from_witness` (HP v0.2, unchanged) gives, for every original canonical coordinate: with a finite checked `R = prod_f max_C U/L` (`check_candidate`, mixed cells -> `R = None`) the one-lower-solve interval `[mu/(mu + R(1 - mu)), R mu/(R mu + 1 - mu)]` on `mu in [d p_lo, d p_hi]` (both endpoints increasing in mu; `one_solve_interval`), and with an upper solve the two-envelope ratio `N^L_j/(N^L_j + N^U_notj)`, `N^U_j/(N^U_j + N^L_notj)` with complements as POSITIVE sums (`csum`), never subtraction. Every division is admitted by `checked_div`. Fixed / factorless rows come from `M.fixed_rows` (exact rationals) and publish only under a positive-mass witness.

Accumulator (`Planner.retained`, `CE.intersect`): indexed by canonical coordinate = original coordinate through `M.orig_of`; `recover` refuses to join two accumulators over different coordinate sets (`Defect`); an empty intersection is a `Defect` (never a preference). Adaptive candidate selection is sound because every intersected interval is an independently valid deterministic statement about the same original task (the deterministic-adaptivity argument of the Hinton-to-Pearl theory; no PAC stream is touched). Normalizer enclosures are intersected only when both bind the same canonical scalar convention (`set_Z` on `M.scalar`-scaled enclosures; a finite R multiplies the lower-solve upper bound).

Zero mass: a canonical scalar 0, a checked zero exact-quotient / identity mass, or a checked zero UPPER mass certify `ZERO_EVIDENCE` (`Refused('ZERO_MASS')` propagates to `fin('ZERO_EVIDENCE')`); a zero approximate LOWER mass is a valid envelope state that yields no witness (`LOWER_ZERO_MASS`, control J). No normalized row publishes without `positive_mass_witness`.

## 3. Epsilon-safe points and publication

`CE.publish` (v0.2): outward `2^-52` compaction, `epsilon_safe_points` (J-box normalization when the J box meets the simplex, else certified-interval midpoints), acceptance `0 <= lo <= pt <= hi <= 1`, width `<= 2 eps`, endpoint radius `<= eps`, row sums contain 1; a variable publishes only when all its rows pass. The planner adds `max_point_radius` to every result. Controls I, E (three tolerances recomputed from the requested eps).

## 4. Scheduling (outside the proof)

Costs are inspectable records: work counts x frozen per-unit rates (`PHASE_RATES.json`, calibrated once on eight DEV controls, max observed x 1.5; kernel 1/20e6 s/row unless slower observed) + the layered route's live-state forecast on the PHYSICAL order (`forecast_bytes`) for memory admission against the executor's usable headroom. `decide()` implements the brief's steps 1-7 verbatim (ready exact / model-bound-promising candidates; `b` by predicted remaining time with the engineering tie rule; optional actions under `D_a + S_a < T_b` and `q_a = min(2 D_a, T_b/4, W - min(W, 2 T_b)) >= D_a`; exploration `q_a = min(2 D_a, W/4)`; the bounded attempt on the remaining work deadline; finalize). Allowances are absolute deadlines on the action's own `Clock`; the global admission stop (3.5 s) and the hard deadline (3.85 s) are separate clocks; `fin` polls the hard clock during assembly and before the commit, and `main` re-checks it before replacing the temporary result file. Candidate-local refusals (`FORECAST`, `MEMORY`, `BITS`, `RANGE`, `PROPOSER`, `NO_SPLIT`, allowance expiry) mark the action failed and return to the queue; a global `DEADLINE` ends new work; `Defect` stops the task; `ValueError / OverflowError / ZeroDivisionError` reaching the boundary become a typed `REFUSED` (never relabelled as a model refusal of a specific kind). Bounds: 1 exact discovery, 1 FAST discovery, 2 refinements, 8 native attempts.

Separation statement: a wrong estimate can only change WHICH valid actions run and whether the task completes in time; it cannot change the validity of any published row, Z enclosure or zero-mass certificate, because none of those read an estimate.

## 5. Pilot 1 measured (records UNIFIED_PLANNER_2026-11-24; protocol frozen at records 6f4f0984d; 64.8 s of 480 charged)

Correctness passed (80/80 + 38/38 controls; every scored row epsilon-safe; 0 disjoint cross-arm pairs; no late success). The three pilot-1 losses are recovered by identity (0.125-0.195 s). Completion preservation FAILED on 2 of 18 (UNIFIED 16 vs union 18): grid4x4_c32_perturbed (FAST alone completes in 0.57 s; in the planner the identity forecast of 168 s forced step 5, exact discovery aliased identity, FAST discovery was ineligible at D 1.03 s > q 0.82 s, and the bounded identity attempt was killed at 3.5 s) and grid4x4_c32_generic (a PAC-only BASE completion, outside the deterministic planner). Compression gains: grid4x4_c32_exact new completion vs both exact comparators (exact quotient, 0.27 s), grid4x4_c16_exact 2.52x vs IDENTITY; the fresh-panel gate (exact and perturbed on one topology) not met. Overhead: none when identity is chosen directly; +0.168 s (50 percent) on grid4x4_c16_generic after a 6-attempt approximate chain. Measured bottleneck: the per-unit kernel rate calibrated on 2-6-state controls over-predicts card-16/32 grid solves by 10-50x, which both starves the cheap FAST construction of its exploration allowance and makes the planner spend the whole budget on an identity solve it believes unaffordable. Decision: revise the scheduling policy (size-spanning calibration; exploration ordering), keep the architecture; STOPPED FOR REVIEW; default unchanged.
