# Consolidation contract and first-stage boundary

The public task is a nonnegative rational UAI model, evidence, original singleton-coordinate queries, an accuracy requirement, time and memory. All recognition, failed construction, execution, recovery and publication count. The interface does not expose a benchmark family or require the caller to select an algorithm.

## Fixed policy

`structural-portfolio-1` is a first, falsifiable integration policy. It has no learned parameters or per-input overrides. It inspects exact source syntax and graph scopes; computes optional bounded min-product physical volumes; recognizes evidence-sliced pairwise forests and binary bipartite components; and compares work with the retained 20-million-row/second planning estimate. This estimate only schedules work and never supports a probability claim.

The first applicable structural candidate gets the remaining work allowance for a forest, an admitted bipartite stream or an affordable pairwise contraction. An affordable higher-arity nonbinary contraction receives a bounded quarter of remaining work before the accepted fallback. Positive pairwise tasks without an affordable exact plan can attempt the checked response route. Nonbinary tasks with an unaffordable identity forecast can attempt checked quotients within one quarter of remaining work, preserving time for the accepted fallback. Other tasks start with accepted block contraction. Early refusals release resources and leave the same request deadline available to the remaining candidates. Each backend is attempted at most once. There is no hindsight best-of-arms result.

These choices are a policy hypothesis, not a theorem of universal preservation or optimal scheduling. Frozen external outcomes determine whether this policy is acceptable. Code and policy must not be tuned between exposed-suite and prospective-evaluation phases.

## Guarantee ownership

The parent owns the original inventory, input binding, absolute deadline, aggregate sampled process memory and final publication. Backends have isolated processes because historical modules use mutable globals and bare imports. All published rows undergo exact rational geometry checks. A deterministic route does not automatically earn an EXACT label; only a zero-width represented answer does.

The fixed PAC allocations are one half of the request delta for block sampling, one quarter for quotient/proposal sampling and one quarter for response sampling. Structural execution spends zero. They sum to the request allowance even when selection depends on earlier results. A backend's own proof must cover its queries/checkpoints within its supplied allowance. Requests disallowing PAC filter those publications. Across attempts, conflicts and infeasible assembled simplex boxes fail closed.

The public result is released only after resource cleanup and final geometry/diagnostics. A late result is suppressed regardless of the backend's success label. Request/refusal inventories remain explicit. Numerical range, zero evidence, invalid source, memory exhaustion and deadline are distinct outcomes.

## What remains intentionally separate

- CQR supports a broader finite-query and normalizer language. It is preserved, not silently reinterpreted as singleton inference.
- SF and CBI expect supplied structured representations; automatic construction from arbitrary UAI tables is not assumed to exist.
- The shipped H4 worker executes a fixed arithmetic cohort. Its historical mathematics and successes remain in the capability ledger; it is not advertised as a current generic UAI backend.
- Historical frozen snapshots remain available for differential tests and receipt identity. Removing them requires a separate dependency and capability proof.

The next extraction step should move implementation responsibilities behind these interfaces without changing outcomes. A cleaner tree alone is not the acceptance result. The first goal is for this single executed policy to recover verified structural capabilities and preserve useful deterministic/PAC completions under the same contract; the broader goal is material scaling advantages over libDAI.
