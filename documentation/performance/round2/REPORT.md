# Incumbent-first automatic inference: full external benchmark

The candidate passes every predeclared release gate. It completes 52 of 61 tasks in both repeats, preserves the 51-task same-round union of the accepted and experimental baselines, and retains all 50 previous automatic completions. There are no confirmed material slowdown flags against the corresponding parent policies. This supports delivering the opt-in automatic policy and runtime repairs. The accepted default is unchanged.

Broad end-to-end speed dominance over libDAI is **not established**. Automatic covers more tasks under the fixed contract, but on 31 mutual completions its median wall-time ratio to libDAI JT is 8.389. It is faster in both repeats on six tasks and slower in both on 22. The result is a coverage advance with some substantial speed wins, not the desired general latency advantage.

## What changed and why

The automatic switchboard retains physically admitted structural routes, including affordable higher-order binary contraction. It now gives the incumbent block solver its remaining allowance before optional quotient construction. An expensive dense identity forecast does not establish that an unbuilt quotient is useful or affordable. Quotients remain available after an early incomplete block return. No benchmark names, task-specific parameters, new fitted rates or thresholds enter dispatch.

The supervisor receives the worker's absolute monotonic deadline; deadline suppression prepares its row inventory before the final timestamp; obsolete UTC parsing is removed from ownership reconciliation; and CLI results preserve the API timestamp separately from publication timing. Ownership verification, cleanup acceptance and late-row suppression remain in force. The earlier pass's lazy imports, lexical inspection fast paths, generic binary structural admission and phase diagnostics are included in the deliverable.

No inference kernel, certificate formula or accepted engine configuration is changed. Full generic access to CBI, SF, H4 and CQR is not claimed: those specialists still require representations or query interfaces beyond the generic UAI routes. See `IMPLEMENTATION.md` and the retained round-1 implementation note.

## Partial answers and validity

Full-completion preservation does not imply preservation of every partial answer. On 1qt9 repeat 2, the parent experimental arm returns 15 of 1,230 coordinates while automatic returns zero. In repeat 1 both return zero. Relative to the previous automatic campaign, which returned 15 in each repeat, the historical loss is 30 coordinate instances. The incumbent-first rule deliberately risks such partial losses when block consumes the allowance. No task exception was introduced. Across cells with at least one incomplete arm, automatic gains 11,716 coordinate instances and loses 15 versus the same-round experimental parent; those aggregate gains do not erase the individual loss.

All 424,891 published coordinate instances pass geometry checks. There are zero deterministic conflicts, zero PAC interval conflicts and zero exclusions in 165,996 coordinate comparisons with JT, using the frozen 5e-10 serialization allowance. No identity, artifact or cleanup validation issue is recorded. No late published answer is accepted.

Two narrow refusal rules were declared before this round: resource-killed comparator outputs are censored nonanswers, and a truthful, clean, zero-row DEADLINE refusal may remain a valid refusal inside the outer contract even when its internal publication timestamp exceeds 19.5 seconds. The latter cannot count as a completion or enter a latency ratio. Claimed publication independently requires consistent finite API/CLI timestamps, not merely a boolean deadline flag. Five JT timeout outputs are censored; one parent experimental 1aie refusal reports 19.530538 seconds with no rows. Neither changes a completion count. The previous round's original validity FAIL is untouched. In that earlier report, the flagged 19.50255564-second value was the CLI publication field, not evidence that the API's authoritative sample itself was late.

## Reproduction and next decision

`results/` contains the unchanged frozen analysis, paired CSV, full cell-summary CSV, freeze and runner return. `qualification/` contains commands and logs. `INDEPENDENT_REVIEW.json` and `.md` record the separate audit. `RAW_ARCHIVE.json` binds the full raw archive: every cell output, launch, log, receipt, ownership record, setup result and executed native artifact. The portable replay checks the frozen analyzer dependencies, all 122 model/evidence bindings and three historical reference files, forbids reads from the original source roots and requires all three reports to match byte for byte.

The bundle is for review and pushing by the user; this pass does not push or merge remotely, and keeps accepted as the default. The next performance question is why automatic still pays large end-to-end costs on JT-easy instances while retaining its coverage advantage. That should be addressed with a predeclared general implementation change and the full external suite, followed by a genuinely untouched evaluation cohort. Neither an instance lookup table nor another claim of universal speedup is warranted by this run.
